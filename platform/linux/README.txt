Arcus Odyssey DX for Linux, version @VERSION@ (@ARCH@)
===================================================

An unofficial fan project: Arcus Odyssey (Wolf Team, 1991), recompiled for modern systems.
This copy was built from your own cartridge ROM, and it contains the game: keep it for
yourself, don't share it.

Play
  ./arcus-odyssey-dx                (or double-click it in your file manager)
  ./install.sh                    adds it to your app menu, with its icon
  Steam Deck / Steam: Add a Non-Steam Game, and pick arcus-odyssey-dx from this folder.

Needs: a 64-bit Linux with glibc @GLIBC@ or newer (Ubuntu 22.04, Debian 12, Fedora 36,
SteamOS 3 or newer), OpenGL 2.1, and X11 or Wayland. Nothing else to install.

Your settings, saves and save states are in
  ~/.local/share/Arcus Odyssey DX/     ($XDG_DATA_HOME/Arcus Odyssey DX/ if you set it)
so this folder can live anywhere, and replacing it with a newer build keeps them.

Controls: any gamepad (Xbox, PlayStation, Switch Pro, Steam Deck), or the keyboard (arrows,
Z X C S V, Enter = Start). The options, save states and extras are in the menu: the
gamepad's Select / Back / View / - button, or Esc.
